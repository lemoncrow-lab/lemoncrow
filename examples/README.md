# Examples

- [`demo`](demo) is the fully populated Review demo: a billing app with a prepared change, several scenarios (`standard`, `orders`, `orders-revision-2`, `large`, and more), and stub states.
- [`empty`](empty) is the empty state: baseline committed, no change, nothing to review. It is a thin wrapper over `demo`.

See [`docs/reference/review-demo.md`](../docs/reference/review-demo.md).
